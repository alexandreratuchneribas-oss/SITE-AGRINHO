Monitoramento Sustentável no Campo

Inovação tecnológica para a Feira Agrinho 2026. Facilitando a vida do produtor rural em Guarapuava.


Conheça o Projeto

O que é o projeto?

Desenvolvido por Alexandre, sob orientação de Thalles Felipe Horn, este aplicativo une sensores de alta precisão com uma interface simples para monitorar a saúde do solo em tempo real.

💧 Umidade

Saiba exatamente quando irrigar, evitando o desperdício de água e preservando os recursos naturais.

🧪 Minerais

Monitoramento de nitrogênio e fósforo para uma adubação precisa e eficiente.

📊 Sustentabilidade

Dados reais que ajudam a equilibrar a produção agrícola com a preservação ambiental.
